# TSA取込・保存

## TSA

- 本番: `https://v0-tsa-19.vercel.app/web-sales/dashboard`
- 対象月を `Report month` と一致させる。
- 対象ECのCSV取込だけを開き、検証結果の `import_file` を選ぶ。
- 自動完全一致または保存済み学習だけを確定する。
- 未紐付け、タイトル空欄、数量差異、商品売上金額の欠損・不正が1件でもあれば確定せず `needs_review` にする。
- 原本の公式商品売上金額を、帳票の金額定義のまま保持する。通常商品マスター単価×個数から再計算せず、送料・店舗クーポン・控除を二重に差し引かない。
- 単月分だけを確定し、原本総数量・総金額を `expectedQuantity` と `expectedAmount` に渡す。未紐付け除外などによる片方でも差異があれば確定しない。
- 登録先は `web_sales_summary` の対象ECの `*_count` と `*_amount`。実売金額未取得はNULL、公式の明示0は0。通常単価・原価のスナップショットを実売平均単価で上書きしない。
- 確定後、CSV総数量とTSA保存数量、公式総金額とTSA保存実売金額の両方を比較する。

## アーカイブ名

- 1日から15日: 既存の `【A】` と `1日～15日` を含む命名を踏襲する。
- 月間: 既存の `【B】` と `1日～月末日` を含む命名を踏襲する。
- 同名ファイルがある場合は上書きしない。末尾に実行日時 `YYYYMMDD-HHmmss` を付ける。
- 元CSVと日付抽出後CSVが異なる場合、元CSVへ `.original`、取込用へ `.prepared` が判別できる名前を付けて両方保存する。

## 完了条件

1. 公式管理画面の店舗、帳票、期間が一致。
2. CSV検証が `valid`。
3. 元CSVと取込用CSVがアーカイブ済み。
4. TSA対象月・対象ECへ登録済み。
5. CSV総数量とTSA保存数量、原本公式総金額とTSA保存実売金額が一致。
