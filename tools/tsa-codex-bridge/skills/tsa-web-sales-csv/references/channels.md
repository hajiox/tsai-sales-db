# EC別CSV取得手順

対象期間は開始日・終了日とも含む。店舗名は会津ブランド館の運用店舗であることを確認する。

## Amazon (`amazon`)

- 管理画面: Seller Central
- 確定直リンク: `https://sellercentral.amazon.co.jp/business-reports`
- 導線: `レポート` > `ビジネスレポート` > `ASIN別` > `（子）商品別詳細ページ 売上・トラフィック`
- 一時タブ復旧時: Seller Centralのルートや既存タブの`/amazonsell/business`へは移動せず、上記の確定直リンクを直接開く。直リンク上で会津ブランド館・日本・Business Reportsが確認できた場合はサインイン済みとして続行する。
- 期間: 画面右上の開始日・終了日にタスク期間を入力する。
- 出力: `CSVダウンロード`
- 承認停止時の限定補助: BridgeはURLが`/business-reports`、店舗が`会津ブランド館`、開始日・終了日がタスク期間と完全一致し、表示ボタンが`ダウンロード（.csv）`である場合だけWindows経由で1回実行する。座標クリックや別帳票への転用は禁止する。
- 必須列: `（親）ASIN`、`（子）ASIN`、`タイトル`、`注文された商品点数`、`注文商品の売上額`
- 注意: `注文レポート`、親商品別、日付別の帳票は使わない。タイトル空欄で数量がある行はAmazon側でも発生するため、TSAで推測せず確認待ちにする。
- 公式確認: https://sellercentral.amazon.co.jp/seller-forums/discussions/t/6f72ee12ade98c24cbc10e5bc28f7ba7

## 楽天市場 (`rakuten`)

- 管理画面: RMS / R-Karte
- 導線: `データ分析` > `4 売上分析` > `商品別売上`
- 確認済み画面: https://datatool.rms.rakuten.co.jp/realtime/item
- 期間: 表示期間をタスク期間へ変更する。端末は `すべて`、消費税は `税込`。
- 出力: `CSVダウンロード`
- 必須列: 7行目の `商品名`、`商品管理番号`、`平均単価`、`売上個数`、`売上`、`売上件数`
- 注意: 3行目の `表示期間` がタスク期間と完全一致することを検証する。店舗売上・SKU別売上・データダウンロードの別帳票は使わない。

## Yahoo!ショッピング (`yahoo`)

- 管理画面: ストアクリエイターPro
- 導線: `プレミアム統計` > `商品分析`
- 確認済み画面: https://pro.store.yahoo.co.jp/pro.aizubrandhall/sales_manage/item_report
- 期間: 範囲指定でタスク期間を入力する。画面表示は末日のみになるが、CSVは指定範囲の合算値になる。
- 出力: `CSVファイルをダウンロード`
- 必須列: `商品名`、`商品コード`、`売上合計値（税込）`、`注文数合計`、`注文点数合計`、`注文者数合計`
- 注意: 売上管理の注文CSV、広告CSV、画像CSVは使わない。

## メルカリShops (`mercari`)

- 管理画面: PC版メルカリShops管理画面
- 導線: `売上` > `売上明細ダウンロード`
- 期間: タスク期間を含む開始月・終了月を指定し、`CSVファイルを作成`。作成後に `ダウンロード`。
- 必須列: `注文番号`、`明細番号`、`明細種別`、`売上移転日`、`商品名`、`数量`、`売上（税込）`
- 日付基準: `売上移転日`。購入日が前月でも売上移転日が対象期間なら含める。
- 注意: 月単位出力なので検証スクリプトが日付範囲外をTSA取込用コピーから除外する。`購入` 以外の明細がある場合は自動確定せず確認待ちにする。生成CSVの有効期限は24時間。
- 公式手順: https://support.mercari-shops.com/hc/ja/articles/4417485760537

## BASE (`base`)

- 管理画面: BASEショップ管理
- 導線: `注文` > 検索条件 > `注文データ` > `全○件をダウンロード`
- 確認済み画面: https://admin.thebase.com/shop_admin/orders
- 期間: `注文日時` をタスク期間へ設定する。履歴と同じ `発送済み` を対象にする。
- 必須App: `注文データダウンロード App`
- 必須列: `注文ID`、`注文日時`、`商品名`、`価格`、`数量`、`合計金額`、`発送状況`
- 日付基準: `注文日時`
- 注意: `売上データダウンロード`、`CSV商品管理`、納品書は使わない。検索結果の全件を出力する。
- 公式手順: https://help.thebase.in/hc/ja/articles/900000133723

## Qoo10 (`qoo10`)

- 管理画面: QSM
- 導線: `配送/キャンセル/未受取` > `配送管理`
- 確認済み画面: https://qsm.qoo10.jp/GMKT.INC.Gsm.Web/Delivery/DeliveryManagementPrime.aspx
- 状態: `配送中/配送完了` を選択する。
- 期間: `注文日` をタスク期間へ設定して照会する。
- 出力: `全体をダウンロード`
- 必須列: `配送状態`、`注文番号`、`注文日`、`商品番号`、`商品名`、`数量`、`販売者商品コード`
- 日付基準: `注文日`
- 注意: 商品SummaryのCSV、選択件のみ、販売内訳は使わない。基本照会設定は既存運用どおりCSV形式を使用する。

## TikTok Shop (`tiktok`)

- 管理画面: TikTok Shop Seller Center
- 導線: `注文` > `注文管理`
- 確認済み画面: https://seller-jp.tiktok.com/order
- 状態: `発送済み`。キャンセル・返品を含めない。
- 期間: `注文の支払い日時` をタスク期間へ設定する。
- 出力: 検索結果を `エクスポート` し、エクスポート履歴からCSVをダウンロードする。
- 必須列: `注文ID`、`注文状況`、`SKU ID`、`商品名`、`数量`、`注文金額`、`注文の支払い日時`
- 日付基準: `注文の支払い日時`
- 注意: 追跡情報テンプレート、商品一括登録、決済レポートは使わない。注文金額0円の無料サンプルはTSAパーサーが除外する。
- 公式手順: https://seller-jp.tiktok.com/university/essay?knowledge_id=2262430524950273
