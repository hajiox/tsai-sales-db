# ECサイト別プレイブック

## 共通

1. 最初にChromeの既存タブ一覧を取得し、各サイトですでにログイン済みの公式販売管理タブを優先して再利用する。ユーザー所有タブは閉じない。
2. 同一サイトの既存タブが複数ある場合、最初のタブが別ブラウザ作業で使用中でも、同じ公式ホストの残りの候補を順に取得する。
3. 全候補が使用中または対応タブがない場合は、同じログイン済みChromeプロファイル内に対象EC専用の一時タブを1枚だけ作成して公式URLへ移動する。別ブラウザ、新規ウィンドウ、シークレット、一時プロファイルは使わない。一時タブだけを最終確認後に閉じる。
4. 商品名、容量、保存方法、形態、識別子を確認する。
5. 現価格を読む。依頼の旧価格と1円程度違う場合も黙って推測せず、現行表示を記録して指定の新価格へ変更する。
6. 入力後の値を読み直してから保存する。
7. 保存後に一覧または再読込でサーバー側の値を確認する。
8. `TASK_JSON.productMappings` が渡されたサイトは、全候補の商品名を検索して商品識別子・容量・保存方法まで照合する。一般名やJANの検索だけで `対象商品なし` にしない。証拠付きで未登録と確認できたサイトだけを除外し、残りのサイトとLPは続行する。

## Amazon Seller Central

1. 在庫管理で商品名、ASIN、SKUを照合する。
2. 対象行の「出品情報の編集」から、同じ取得済みタブを価格・出品情報だけの `.../interactive/listing/workflow/edit/offer?...` へ移動する。新しく開かれたタブは使わず、SKU、ASIN、商品種別、Marketplace IDを現在の商品行または編集URLから引き継ぐ。
3. URLのパスに `/offer` が含まれること、商品名・SKU・ASINが対象商品と一致することを確認する。`/product_details` の商品詳細全体は価格だけの更新に使わない。
4. 「商品の販売価格」を全選択して新価格を入力し、Tabなどで変更イベントを確定してから価格専用画面の「保存して終了」または「送信」を押す。
5. 「変更が送信されました」を確認し、「完了」を押す。
6. 一覧を再読込して価格を確認する。

送信後に商品詳細画面へ移動して `90220: この商品はAmazon.co.jp限定商品ですか？ は必須` が出た場合は、対象商品が同一商品として楽天・Yahoo・BASE等でも販売されていることを `verified-products.md` またはTSAの紐付けで確認する。複数EC販売が確認できる商品に限り、「この商品はAmazon.co.jp限定商品ですか？」だけを `いいえ` に設定して保存する。他の商品属性は変更しない。保存後は `/offer` の価格専用URLへ戻り、新価格を入力・送信して保存値を再確認する。複数EC販売を証明できない商品では回答を推測せず、商品属性未確定として停止する。

Amazonが「承認された場合、24時間以内に反映」と表示し一覧が旧価格のままなら、「変更送信済み・反映待ち」と報告する。再送を繰り返さない。

## 楽天RMS

1. 容量や商品名で検索し、商品管理番号まで照合する。
2. 一覧の価格欄をクリックし、`Ctrl+A` 後に新価格を入力する。
3. 入力マスクがあるため、値が旧価格へ追記されていないことを確認する。
4. 「更新」を押し、「更新しました」を確認する。
5. 対象行に新価格が表示されることを確認する。

## Yahoo!ショッピング

1. 商品名検索で対象商品コードを確認し、商品編集を開く。
2. 「通常販売価格（税込）」を変更する。同じ商品の自動切替設定にも同額の通常価格が残っている場合は、将来の復帰を防ぐため両方を変更する。
3. 「保存して編集を続行」を押し、保存後の値を確認する。
4. 「反映管理」を開き、「反映」を押す。
5. 確認画面の対象商品コード・商品名を照合して「はい」を押す。
6. 「未反映項目はありません」を確認する。

## メルカリShops

1. 商品名または商品管理コードで検索する。
2. 対象商品を開き、販売価格を全選択して変更する。
3. 「公開設定に進む」から「更新する」を押す。
4. 商品一覧の新価格と「商品を公開しました」を確認する。

## Qoo10 QSM

1. 検索条件を「商品名」にし、現行容量で検索する。過去に商品名が修正されている場合は古い容量で決めつけない。
2. 商品番号と商品名を照合する。似た商品を区別する。
3. 対象行の「修正」を展開し、展開行の「修正」から商品編集を開く。
4. 最初の「最大99,999,999」が販売価格。割引価格や在庫欄と取り違えない。
5. Qoo10のマスク欄は `fill()` で旧価格へ追記されることがある。欄をアクティブにし、`Ctrl+A` 後に入力する。
6. DOM表示が新価格だけになったことを確認して「修正する」を押す。
7. 画面右側の販売価格と一覧の両方で新価格を確認する。

誤って追記された値は保存前に直す。保存後に右側の販売価格が旧価格なら完了していない。

## BASE / TikTokショップ

1. 商品名、容量、SKU、ASINで検索する。
2. TikTokショップがBASE連携なら、`【TikTok連携】` を含む商品だけを編集する。
3. 通常BASE商品とTikTok連携商品を混同しない。
4. 各商品の送料設定を確認する。送料別商品は総額の改定差額だけを現行BASE価格へ加え、`【TikTok連携】【送料無料】` など送料無料の商品は他の送料無料モールと同じ新価格にする。

例: 他サイトが4,290円から4,550円なら差額は260円。送料別のBASE通常品が3,990円なら新価格は4,250円。送料無料のTikTok連携品が4,290円なら新価格は4,550円。

検索結果が0件なら変更しない。TikTok Seller Centerへ切り替えて類似商品を編集しない。
