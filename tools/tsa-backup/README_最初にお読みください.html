TSA業務PC 復旧手順

このUSBは、業務PCに障害が起きた時の復旧用です。バックアップ本体は社内NASとGoogle Driveにあります。

復旧確認が終わるまで、FAX、メール監視、EC速報、定期送信を開始しないでください。二重送信を防ぐためです。

Windowsが起動しない

  1. 交換SSDまたは代替PCを用意します。
  2. Windows回復環境の「イメージでシステムを回復」を開きます。
  3. NASの \\tshdd\disk\NEW\TSA-PC-Backup\system-image にある最新の正常スロットを選びます。
  4. 復元後、下の確認を終えてから外部送信を再開します。

データだけ戻す

管理者PowerShellでこのUSBを開き、次を実行します。既定では検証・展開だけで、本番データを上書きしません。

Set-ExecutionPolicy -Scope Process Bypass
cd D:\TSA-PC-RECOVERY
.\Restore-TsaPc.ps1 -ListOnly
.\Restore-TsaPc.ps1

NASが使えない場合: .\Restore-TsaPc.ps1 -SourceRoot 'G:\マイドライブ\TSA-PC-Backup\daily'

復旧後の確認

  1. SQLite検査がok。
  2. TSA、TSG、DocScanner、ヤマト管理へログイン可能。
  3. 書類・FAX・メール・EC速報の直近データがある。
  4. PM2とタスクスケジューラに二重起動がない。
  5. テスト宛先だけで外部連携を確認。
  6. 問題がなければ監視・送信を一つずつ再開。

通常の確認

TSAサイドバーの「バックアップ管理」で、日次01:30、日曜03:00、監査06:30の履歴を確認します。定期処理はログイン前からPM2で動作し、結果をTSAへ保存します。詳細版は同じUSBの PC復旧手順.md です。
