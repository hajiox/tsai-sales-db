# DocScanner 製造入力の社内Web入口（2026-10-15）

スタッフは社内Wi-Fiから固定QR、または通常DocScannerメニューの「製造入力」で入力ページを開きます。端末登録・登録コード・ログインは不要で、入口に有効期限はありません。スマホへの証明書追加、VPN設定、会社ドメイン設定の案内は撤回しました。

- 製造入力：`http://192.168.110.200:8444/staff/char-siu-production`

TSAの既存 `GET /api/docscanner-staff-setup` は、旧QRや保存済みリンクのために残し、製造入力リンクだけの短い案内へ変更します。証明書ファイルを読まず固定HTMLを200で返します。要求パラメータ、登録コード、端末資格、原価・財務情報を含めず、外部JS・画像・解析・フォーム・書込みもありません。

DocScannerは社内共通の入力先を使い、途中入力は各ブラウザー内に保持します。入力者名は自己申告です。端末―社内PC間のHTTP通信は暗号化されません。原価・単価・賃金・正式登録はTSAの管理者画面に分離します。

互換性のため、旧 `GET /api/docscanner-staff-setup/certificate` と単一公開DER assetの検証は保持します。証明書の配布リンクや導入手順は案内画面から削除し、スタッフへ導入を求めません。旧配布経路は固定ファイルだけを読み、自己署名CA・期限・全バイト一致・1byte–16KiBを検証して、不正・欠落時は内部情報を出さず503にします。秘密鍵・PFX・パスフレーズは扱いません。

両GETのno-store、nosniff、frame拒否、no-referrer、CSPと既存output tracing設定を保持します。合成検証は固定LAN入力リンクだけの表示、登録ボタン・登録必須案内の撤回、案内ページのファイル読取ゼロ、証明書欠落時も案内200、旧証明書GETの検証・固定503・安全なレスポンスを確認します。公開とDocScanner実入口の稼働・端末確認は別途行い、TSA公開案内だけで厨房端末の利用完了とは扱いません。
