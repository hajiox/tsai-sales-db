# 2026-09-15 SNS手書き文字モード

- 通常リサイズ・クリエイティブ・アレンジに加えて `handwritten`（手書き文字）を追加。UI、API許可リスト、履歴表示、全媒体/個別再生成のSchemaとBridgeを一致させた。
- 保存済み商品ポイント・紹介文から短い特徴を選び、ImageGenで太い縁取りの手書き文字と対象への矢印を写真と一体生成。重量やセット内容は入力だけを根拠にする。Xは原則2注釈、他媒体2〜4注釈、1注釈12文字・最大2行を目安とする。
- creativeの後付け見出しは重ねない。最終変換はhandwrittenだけ全体保持（contain、余白は白系）とし、既存モードの中央クロップは保持。画像内日本語の品質はImageGenによるため、実素材は生成後のプレビューで確認できる。
- Bridgeとサーバー要求バージョンは1.9.92で揃える。稼働PCでは全Workerの待機を確認し、既存ファイルをバックアップしてBridge・両Schema・生成Skillを更新する。
- 全媒体結果、4媒体それぞれの個別再生成、未対象媒体保持、モード/元画像誤指定の拒否、端の注釈保持を検証。既存SNS/Bridge/Skill契約とsecurity/RLSを通過。
- 共有同期は共有repoの既存未コミット変更で保留。当該SkillはTSA同梱版とローカル配布先に反映。保存済み素材や投稿済み画像は変更しない。
