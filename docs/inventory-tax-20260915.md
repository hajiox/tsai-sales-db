# 2026-09-15 棚卸しの税込・税別併記

- 対象は棚卸しだけ。店舗、製造、倉庫、他店、食のブランド館、財務内の決算棚卸し一覧、各Excel/CSV/印刷を併記へ変更。財務帳簿・KPIの計算は変更していない。
- 店舗・倉庫は税別原価から換算。製造は保存済み税込原価から換算。他店の7月実売単価はユーザーが税込と確認したため、税込原価から8%を逆算。
- 単価の小数は保持して数量を掛け、明細金額で円未満を切り捨てる。税別・税込を別々に合算。食のブランド館は元Excelの税率式と税別/税込合計を採用し、シート単位の端数処理を保持する。
- 製造の税率は食材8%、資材10%。本みりん、本料理清酒、HEIKO OPPシートは10%。品目ごとの0/8/10%上書きを追加し、APIで検証。既存単価と数量を変更せずに換算できる。
- 元Excelのセル位置・式は保持し、税別/税込列を付加。倉庫Excelは除外品を集計対象から外す。既存CSVに加え、店舗・製造にもxlsx出力を追加。
- 本みりんマスターの異常価格を、既に承認された推定仮単価へ修正。直接10明細と依存先を含む15レシピの原価を再計算。数量、販売価格は変更していない。トランザクション前にローカルへ原本バックアップ。推定単価の根拠確認は未了。
- 名称と入数が不一致の蕎麦・塩・白玉麩・みょうばんは確認待ち。欠落単価を推測で補完していない。
- 確認：税換算・既存棚卸し丸め・財務一覧/Excel回帰、ESLint（既存warningのみ）、security/RLS、webpack build。全体tscには既存エラーがあり、変更ファイルのエラーは解消。
