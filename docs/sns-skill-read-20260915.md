# 2026-09-15 SNS素材生成のSkill読み取り誤検出

- 手書き文字ジョブで許可済みimagegen/SKILL.mdのGet-Contentが禁止操作扱いになった。原因はWindowsのスラッシュ表記差と、同じitemの完了イベントでcommandが省略されるCLI形式への未対応。
- 読み取り先はimagegenのSkill1ファイルのまま、区切り文字を正規化。PowerShellラッパーを明示した既知の実行形式だけに限定し、コマンド全体を検証する。完了イベントは同一ジョブ内で検証済みのitem IDに限り受理。未知ID・別ジョブ・不許可コマンドは拒否。
- 実障害イベントと回帰テストで、スラッシュ/バックスラッシュ、引用、本文省略、別ファイル、任意実行ファイル、複数コマンドを検証。Bridge/サーバー要求バージョンを1.9.93に統一。
- 本件は手書き文字の画像生成能力やSNSのログイン失敗ではなく、生成後のBridge検証処理の不備。全画像生成モードに共通して適用する。
