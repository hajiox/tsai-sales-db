# 2026-09-15 SNSクリエイティブ文字の可読性

- 横長画像の高さ基準の小さい文字と、短文を1行に縮める処理を廃止。幅360pxで見出し20〜24px・補足14px・ブランド12px相当を確保し、実測した高さで改行と配置を決める。
- ストーリーは上下14%の安全余白を確保。既存の長いコピーは必要に応じて文字領域を広げ、文言を削除しない。最低文字サイズでも収まらない異常な長文は、切れた画像を保存せず明示エラーにする。
- 生成Skillは原則見出し14文字・補足20文字に整理。詳しい条件は投稿本文へ残し、誤解を招く省略はしない。画像生成時に大きな文字用の背景余白を確保する。
- 4媒体×2配置×3コピーの24描画ケースで画像寸法・文字サイズ・安全領域を検証し、幅360pxの出力を目視確認。Bridge・Skill契約、Skill構文、security/RLS検証を通過。
- 変更は次回のクリエイティブ生成・再生成から適用する。保存済み素材・投稿済み画像は変更しない。レンダラーとSkillは各ジョブで読み込まれるため、Bridge本体のバージョン変更や稼働ジョブの再起動は不要。
- 共有同期は共有repoの既存未コミット変更により保留。当該SNS SkillはTSA repo同梱版で管理し、検証後にローカル配布先へ反映する。
