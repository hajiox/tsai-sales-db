# TSA AIチャット運用記録

## 2026-09-07 — API入力の有界化と利用量計測

- 売上・広告チャットは既存のGemini APIとモデルを維持。最新質問は全文を保持し、過去会話は直近の完結した質問・回答単位で最大12メッセージ・24,000文字を送信する。これは過去履歴の上限であり、最新質問と根拠データは切り詰めない。
- 古い会話を省略した場合、モデルには未送信の条件を推測せず、回答に必要ならユーザーへ確認するよう伝える。DB集計・媒体知識は維持し、売上JSONのインデントのみ除去した。
- `ai_chat_usage` はversion 1、system/provider/task/model/status、入力・出力・キャッシュ・thinking・総トークン、durationMs、会話件数・文字数だけを記録。APIが返さないトークン数はnull。本文、顧客名、資格情報、レスポンス全文は保存しない。ロガー障害で回答を失敗させない。
- 共通処理: `lib/ai-chat-context.ts`。検証: `node --experimental-strip-types scripts/test-ai-chat-context.mjs`（上限、最新質問、古い条件、省略、入力検証、数値限定ログ、ロガー障害）。対象eslint、helper単体tsc、秘密検査、読取専用RLS検査、production build（188ページ）に合格。buildの全体型検査は既存Next設定で省略される。
- 制限: 実モデルを呼ぶ試験や実トークン削減率の比較は未実施。今後の同種リクエストのusageで評価する。長い最新質問や大きな根拠データ自体の大きさは本変更で制限しない。
